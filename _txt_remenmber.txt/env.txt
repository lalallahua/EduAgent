生成随机密码是什么意思：
POSTGRES_PASSWORD="$(openssl rand -hex 16)"
MINIO_PASSWORD="$(openssl rand -hex 20)"

如果需要修改密码 那么首先得再执行一次生成随机密码 
NEW_POSTGRES_PASSWORD="$(openssl rand -hex 16)"
NEW_MINIO_PASSWORD="$(openssl rand -hex 20)"
然后修改.env的 POSTGRES_PASSWORD 以及DATABASE_URL

执行：
sed -i \
  "s/^POSTGRES_PASSWORD=.*/POSTGRES_PASSWORD=${NEW_POSTGRES_PASSWORD}/" \
  .env

sed -i \
  "s|^DATABASE_URL=.*|DATABASE_URL=postgresql+asyncpg://eduagent:${NEW_POSTGRES_PASSWORD}@127.0.0.1:5432/eduagent|" \
  .env

sed -i \
  "s/^MINIO_ROOT_PASSWORD=.*/MINIO_ROOT_PASSWORD=${NEW_MINIO_PASSWORD}/" \
  .env

然后把shell中的临时密码变量删掉
unset NEW_POSTGRES_PASSWORD
unset NEW_MINIO_PASSWORD

增加CourseDocument endpoint:
services/course_service/app/api/routes/content.py

from services.course_service.app.services.course_document import (
    assemble_course_document,
)

@router.get(
    "/courses/{course_id}/versions/{version_id}/document",
)
async def get_course_document(
    course_id: UUID,
    version_id: UUID,
    owner_id: UUID = Depends(current_user_id),
    db: AsyncSession = Depends(get_db),
):
    try:
        document = await assemble_course_document(
            db,
            course_id=course_id,
            version_id=version_id,
            owner_id=owner_id,
        )

    except LookupError:
        raise HTTPException(
            status_code=404,
            detail="Course version not found",
        )

    return document.model_dump(
        mode="json"
    )
