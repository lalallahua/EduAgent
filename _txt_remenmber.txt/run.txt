切换用户：
su - eduagent

检查是哪一个用户在执行操作：
whoami

激活创建的虚拟环境
source .venv/bin/activate

启动基础设施：
docker compose up -d 

-d 表示的意思时后台运行

查看：
docker compose ps

查看日志：
docker compose logs --tail=100

确保PostgreSQL已经运行：
如果没有运行：
docker compose up -d --pull never
测试PostgreSQL:
docker exec eduagent-postgres   pg_isready -U eduagent -d eduagent
应该返回：
/var/run/postgresql:5432 - accepting connections

创建一个course tmux 启动 Course Service
tmux new -s course
uv run uvicorn \
  services.course_service.app.main:app \
  --host 0.0.0.0 \
  --port 8001 \
  --reload

启动API Gateway先启动一个新的tmux
tmux new -s gateway
uv run uvicorn \
  services.api_gateway.app.main:app \
  --host 0.0.0.0 \
  --port 8000 \
  --reload
